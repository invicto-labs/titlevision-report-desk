    Settings & updates

    Shared team workbook

    Local only

    Use Report PC on the one computer that collects reports. On other computers, choose Viewer PC to show the same saved Excel values automatically. Edit the workbook in the shared folder, one person at a time, then save and close Excel.

    Employee name mapping

    Use a private employee mapping JSON file to show official Search and Typing names when TitleVision usernames differ. This file stays on this Windows PC and is preserved during updates. New reports use it automatically. To update names already in a Main workbook, click Check latest error status for that month.

    Contributor rules

    Search uses the last completed human Search, AESearch, or UpdateSearch task.

    Typing uses the last completed human TypingModule task.

    Triage / VM Team / Leadership displays the team itself. An explicit category identifies the cause; unclear notes are flagged for review.

    Other Specs-Standards and Quality Control errors stay unassigned. Both Searcher and Typer are retained so you can change Team in column D and see the final contributor update.

    Multiple matching products are checked by product number and committed date. If same-day candidates have identical completed Search and Typing users, the report keeps a review flag; differing histories stop the report.

    Application updates

    Loading version…
    Check for a published release.

    Get update downloads the latest verified installer. If a report or refresh is running, it waits for completion, then restarts the app automatically. Your sign-in, reports and schedule are preserved.

    Private GitHub release access

    For private releases, an existing Git sign-in as invicto-labs works on this PC. Otherwise, save a fine-grained token with Contents: read permission for this repository. Saved tokens are encrypted on this PC.
